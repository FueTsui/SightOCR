## 安装、升级与更新

**首次安装**：运行安装包并在 Windows 中确认管理员权限后，窗口只显示 SightOCR 图标、名称与版本和一个「立即安装」按钮。点击底部「自定义选项」可修改安装位置与选项（开始菜单快捷方式、桌面快捷方式、开机自动启动、始终以管理员身份运行、安装完成后运行 SightOCR）。默认安装到 `C:\Program Files\SightOCR`，开始菜单快捷方式与「安装完成后运行」默认勾选。Enter 执行主按钮，Esc 取消。

**覆盖安装（升级 / 修复）**：运行新版安装包时沿用当前安装目录（不可更改）；主按钮显示「立即升级」（同版本为「重新安装」），按钮下方提示将从哪个版本升级，并说明已保存的设置、API 密钥和模型接口会保留。自定义选项按当前状态预先勾选。同一目录原地升级，不先卸载旧版，开始菜单 / 任务栏固定项、快捷方式、开机启动与管理员运行选项保持不变；完成页提示已升级。新文件先全部解压并逐个校验 SHA-256，再整体替换；任一文件无法替换时恢复全部原有文件，原版本仍可启动。从 Inno Setup 安装的 2.0.x 升级时，清除旧的 `unins00x.exe/.dat/.msg`，安装登记改由新版卸载程序 `unins000.exe` 接管（沿用原登记项，「已安装的应用」中不会出现重复条目），并删除不再随包提供的开发文档。旧版本位于其他目录（早期的 `%LOCALAPPDATA%\Programs\SightOCR` 或 32 位目录）时，仍先备份旧配置、卸载旧版并迁移到 `Program Files`。已安装更新的版本时，运行旧安装包会先询问是否降级。

**程序内更新**：默认每天在后台检查一次 GitHub 正式版本（可在「设置 → 常规 → 自动检查更新」关闭；启动 20 秒后才进行首次检查，重启不会重复检查）。发现新版本只在工具栏显示「新版本 vX」标记，不会自动下载或安装；点击标记打开「关于 → 软件更新」，可查看版本说明与安装包大小，选择「下载并安装」「跳过此版本」或打开发布页面。下载可随时取消；下载完成并通过大小、SHA256 与程序头校验后，可「立即重启并安装」（识别或翻译进行中时暂不可点），或保持「退出 SightOCR 时自动安装」，从托盘退出时安装且安装后不自动重新打开。更新后首次启动在状态栏提示「已更新到 vX」。

**卸载**：在 Windows「已安装的应用」中卸载时，卸载窗口提供「同时删除设置」（包括已保存的 API 密钥、模型接口、快捷键和偏好设置），默认不勾选，重新安装后可继续使用；静默卸载始终保留设置。卸载程序退出后自动删除自身和空的安装目录。

2026-09-08 起包内增加 `sightocr-mcp.exe` 和 [MCP 文档](MCP.md)。MCP 与桌面程序共用配置和模型目录；安装器会检查同目录两个程序的运行状态。升级前请关闭客户端启动的 MCP 服务。当前版本为 2.1.1，安装包校验值见发布附件 `SHA256SUMS.txt`。

当前发布文件为 `dist/installer/SightOCR-Setup-2.1.1.exe`，版本为 2.1.1，包含程序、OneOCR 引擎和模型、README、LICENSE 与文档。程序和安装包的产品名称、文件描述统一为 SightOCR，第一方发布者及版权作者为 FueTsui。默认安装到 `C:\Program Files\SightOCR`，安装时需要管理员权限；要求 Windows 10/11，支持运行 x64 程序的系统。Arm64 模拟环境尚未验证。相同版本号的不同构建请通过发布文件校验和区分。

本次构建补齐多语言字体覆盖，并用 Windows 原生编辑控件处理复杂文字连写及双向排版；修复识别完成后正文黑屏、旧画面残留及语言菜单遮挡问题，并取消不变正文的重复擦除和重绘，避免日期、时间、数字和其他识别文字持续闪烁。修复正文未聚焦时无法滚轮滚动的问题，原文和译文按鼠标所在位置各自滚动，语言菜单不会穿透滚动正文。取消识别/翻译会终止独立任务进程并立即恢复界面。百度、腾讯公式的 LaTeX 显示块格式和设置「代理」名称继续保留。2.0.0 用户可以升级到 2.0.1。默认客户区为 740×680 逻辑像素，最小为 740×580，支持调整大小和最大化。

手动安装或卸载发现目标安装目录的 SightOCR 正在运行时，窗口内提示将自动关闭它，主按钮变为「关闭并安装」/「关闭并卸载」；再次点击后先请求程序正常退出，旧版或无响应程序在等待 5 秒后结束，再继续。点击「取消」会退出并保留正在运行的程序。关闭程序会丢失未保存的识别内容。

普通静默安装不自动启动程序，未获关闭确认时也不结束运行中的程序。程序内更新使用 `/UPDATE /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="当前程序目录"`，等待程序正常退出最多 120 秒，为进行中的网络任务清理预留时间，随后覆盖安装并自动启动一次新版；如果程序未能退出，安装器会停止，不强制结束或替换正在使用的文件。所有关闭操作均核对进程的完整 EXE 路径，不关闭其他目录中的 SightOCR。程序内更新时若此安装目录的 MCP 服务正在运行，安装停止并提示先停止服务。

命令行参数与原安装包兼容（不区分大小写）：`/SILENT`（仅显示进度）、`/VERYSILENT`（无窗口）、`/SUPPRESSMSGBOXES`、`/NORESTART`、`/DIR="目录"`、`/LOG="日志文件"`、`/TASKS=startmenu,desktopicon,autostart,runasadmin`（列出的选项勾选，其余不勾选）、`/UPDATE`、`/NOLAUNCH`。未指定 `/LOG` 时日志写入 `%TEMP%\SightOCR-Setup-时间.log`。退出码：0 成功；1 安装包损坏或参数无效；2 用户取消（含拒绝管理员权限）；3 安装失败且已恢复原有文件；7 无法关闭运行中的程序或移除旧版，未替换任何文件。安装需要管理员权限：安装程序以普通权限启动后请求 Windows 确认，安装完成后以普通用户权限启动 SightOCR。

下载使用已保存的代理配置，仅接受官方发布中版本匹配的安装包，并验证文件大小、SHA256 和 Windows 程序头；版本说明只用于显示，不作为校验依据。下载失败或取消会清理临时文件；交接成功后由临时目录内的独立更新程序等待原进程退出、再次校验安装包并跟踪安装退出码。安装失败时显示原因、提供安装日志路径并尝试重新启动 SightOCR。「退出时安装」向安装器传入 `/NOLAUNCH`，安装成功后不自动启动。

2.1.1 起，点击「立即重启并安装」前检查同一安装目录中的 MCP 服务，若仍在运行则显示占用进程并保留已下载的更新包，停止服务后可再次安装。退出时无法启动更新也会显示原因。「退出码 7」表示安装准备未完成；新版更新辅助程序会从安装日志提取具体失败原因，而不只显示退出码。通过 Codex 等客户端使用 MCP 时，只关闭 SightOCR 桌面窗口不会停止 MCP；请先断开客户端中的 SightOCR 服务，必要时退出该客户端，再重试更新。

可在 Windows「已安装的应用」中卸载，或运行安装目录中的 `unins000.exe`（静默卸载：`unins000.exe /VERYSILENT /SUPPRESSMSGBOXES`）。卸载移除本次安装的文件和指向本安装的快捷方式，并可选择删除 `%APPDATA%\SightOCR`（设置与密钥）和 `%LOCALAPPDATA%\SightOCR`（升级备份），默认保留；用户自行创建的文件始终保留。仅当开机启动项精确指向本次安装路径时移除该启动项。

## 构建

```powershell
# 检查、测试、构建便携目录并生成正式安装包
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Installer
```

安装包由 SightOCR 自带的安装程序 `SightOCR-Setup.exe`（源码 `rust/setup/`，随 `cargo build --release --bins` 一起构建）生成，不再需要 Inno Setup。构建脚本执行 `SightOCR-Setup.exe --pack dist\SightOCR dist\installer\SightOCR-Setup-<版本>.exe`：便携目录中的程序、模型、README、LICENSE、`skills/` 与 `docs/*.md` 逐个压缩后附加在安装程序之后，并记录每个文件和整体数据的 SHA-256。安装前先校验，损坏的安装包不会安装任何文件。安装目录中的 `unins000.exe` 是同一程序，只附带文件清单。SightOCR 安装包目前未配置代码签名。

## 隔离验证

```powershell
# 需要 PowerShell 7；-Updater 指定一个 2.0.x 的 SightOCR.exe（默认使用本机已安装的版本）
pwsh -NoProfile -File scripts/test-installer.ps1
```

脚本构建调试版安装程序，并用 `scripts/installer/ShutdownFixture.cs` 生成的合成程序代替 SightOCR，打包成测试安装包后依次验证：全新静默安装（逐文件比对、登记、默认快捷方式、不自动启动）；**用 2.0.x 程序真实的程序内更新流程**（`--apply-update`）升级模拟的 Inno Setup 2.0.3 安装，确认等待原程序退出、替换文件、清除旧卸载程序与 Inno 登记值、保留设置文件 / 管理员运行 / 开机启动 / 快捷方式并重新启动一次；MCP 服务运行时拒绝更新；文件被占用时完整回滚；早期默认目录迁移到 Program Files（备份旧配置、`/TASKS`、`/NOLAUNCH`）；静默卸载及自删除；损坏安装包被拒绝。

测试只在调试版本的 `SIGHTOCR_SETUP_TEST_ROOT` 隔离模式下运行：Program Files、开始菜单、桌面与 AppData 均重定向到 `target/setup-test-*`，安装登记与开机启动写入 `HKCU\Software\SightOCR.SetupTest` 并在结束时删除，不需要管理员权限，也不会改动本机已安装的 SightOCR；正式版本忽略该变量。日志保留在对应测试目录。

安装窗口提供“开机自动启动”复选框，首次安装默认不勾选；勾选后在用户登录时以 `--silent` 启动。选项读取现有开机启动状态，取消勾选会移除启动项；自动更新保留当前状态。卸载移除启动项。安装包包含通用 `skills/sightocr/SKILL.md`。

安装窗口提供“始终以管理员身份运行”，首次安装默认不勾选。勾选后，直接启动、快捷方式和开机启动均在创建窗口与注册热键前通过 Windows UAC 请求提升权限；取消 UAC 则退出本次启动。此选项保存在安装目录的 `run-as-admin` 文件，重新安装时取消勾选可关闭，自动更新保留，卸载清除。OCR 子进程继承桌面程序权限；独立 MCP 服务保持客户端的权限。管理员运行不绕过网页自身的快捷键限制。

也可在“设置 → 常规”的“开机自动启动”上方切换“以管理员运行”。点击保存后下次启动生效，当前识别内容不会因切换而重启丢失。该开关读写同一安装选项；安装目录不可写时，保存会请求 UAC，由固定用途的辅助进程更新当前安装的标记文件。取消权限请求会保留原设置并显示保存失败。

## 安装前移除旧版与截图缓存

安装程序在替换文件之前检查当前用户和本机的 32/64 位 SightOCR 安装登记，按精确登记项找到旧版。目标目录原地升级；其他目录中的已登记旧版先关闭其进程、备份配置，再静默调用其卸载程序（Inno Setup 或新版卸载程序均可）。旧版卸载失败或登记损坏时停止安装，不继续覆盖。便携目录和没有对应安装登记的目录不会被递归清空。

2.0.2 修订安装包先按目录合并安装登记，再选择该目录中可用的卸载程序，避免同目录残留的无效卸载登记阻断升级。仅在确认旧程序已移除、登记没有发生变化后，清理对应的残留登记。若程序仍在但全部卸载程序均不可用，安装仍会停止。旧更新器通过 `/UPDATE /DIR` 指定历史默认用户目录或 32 位 Program Files 目录时，安装器会迁移到 `C:\Program Files\SightOCR`；自定义安装目录保持原位置。已经安装 2.0.2 的用户需手动下载修订安装包，同版本不会触发自动更新。新版安装程序沿用上述规则。

用户配置仍保存在用户配置目录。旧安装目录的 config.json、paths.json 在卸载前备份到 `%LOCALAPPDATA%\SightOCR\UpgradeBackup\时间戳-序号`，用户自行放入的文件由原卸载清单之外保留。自动更新恢复原有管理员启动与开机启动选项。

Rust 截图由内存缓冲经匿名管道传给 OCR；识别完成、取消或退出后由内存所有权与子进程回收机制释放，没有临时截图路径。导入的图片仅被读取，不会自动删除。为处理历史残留，应用启动时及每 24 小时清理 `%TEMP%\SightOCR\screenshots` 和 `%TEMP%` 下超过 72 小时的 `sight_YYYYMMDD_HHMMSS.png`，仅匹配文件，不递归，也不跟随目录联接或符号链接。
