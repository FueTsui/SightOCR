# Windows 11 截图工具风格

以用户提供的 Windows 11 截图工具截图为视觉参考。本次修改直接用于 Rust/egui 桌面程序，沿用现有识别、翻译、热键、托盘及配置机制。

## 功能布局

- 工具栏：单行排列新建、截图识别/截图并翻译模式、内容类型、引擎，以及图钉和齿轮。选中的模式用蓝色短线标识；图标按钮提供悬停名称。图钉直接切换置顶，齿轮直接进入常规设置，云端识别精度在引擎选择中设置。
- 空白状态：中央显示当前模式对应的真实快捷键；可开始截图或点击输入文字。翻译模式同时显示目标语言与服务选择。「新建」遵循当前模式。桌面界面不再提供图片导入或拖放识别；文件 OCR 保留在命令行 `--ocr`。
- 结果区：默认宽度以原文/译文分页切换，窗口加宽后左右对照。识别完成时立即展示原文，译文区域继续呈现翻译等待状态。语言位于卡片顶部，服务和复制/翻译操作位于底部；长文本只滚动编辑区域。原译文正文由 Windows RichEdit 处理字体绑定、双向文本、复杂文字连写、选择、编辑与输入法；按 UTF-16 与 Rust Unicode 字符串往返，保留原始字符顺序。子控件随页签、设置、等待状态和弹出菜单切换显隐，避免覆盖菜单。
- 设置：「返回」与「常规、接口、快捷键、代理、关于」五项 Pivot 导航位于同一行。常规直接展示应用主题、合并文本换行、开机自动启动和隐藏托盘图标；接口管理服务凭据和模型；快捷键独立成页，位于接口与代理之间；关于页显示真实 Logo、版本与配置路径，移除产品简介与自动更新流程说明，退出位于托盘菜单。语言与翻译服务继续在工作台选择。输入内容独立滚动，底部固定「保存」与「取消」；外观与快捷键仍仅在保存成功后应用。
- 状态：普通识别与翻译的等待页显示识别/本地回退/翻译阶段、本次任务的服务快照、目标语言、已用时间与取消按钮。修改设置不会把等待页误标为另一家服务。忙碌时禁止修改输入与语言；取消后丢弃迟到的进度与完成事件，保留已展示的原文。静默识别不自动打开等待页或结果窗口。

## 结果置前、后台运行与精简设置

2.0.1 中关闭按钮统一只隐藏主窗口，不以图标或系统集成是否可用决定进程寿命。主窗口另有独立的激活消息入口：再次启动时优先通知后台服务；该服务不可用时，直接通知带有 SightOCR 标记的主窗口，再由 UI 线程恢复显示。此入口仅传递显示意图，不直接修改窗口可见性，截图和退出仍可撤销待显示操作。

普通识别完成和主动打开界面时，先提交最终显示意图，下一帧在主窗口线程恢复并置前。未固定置顶的窗口仅在置前时临时提升，随后回到普通窗口层级；保留置顶选择、用户调整的尺寸及最大化状态。Windows 仍决定是否授予键盘前台焦点。

事件转发只负责唤醒，不提前恢复窗口。同帧中的新截图、关闭或退出会取消此前待执行的显示意图；截图和静默任务保持隐藏，迟到或取消的任务不触发弹窗。关闭主窗口始终隐藏到后台，与托盘图标显示状态无关，即使 Platform 系统集成初始化失败也不结束进程。`--silent` 启动保持隐藏；系统集成正常时再次启动程序可恢复已有实例。托盘「退出」明确结束进程，「重启」释放当前实例后再启动。

独立快捷键页直接按静默识别、截图识别、截图翻译排列录入控件，移除页内重复的「快捷键」分节标题。常规页移除「外观、识别结果、启动与托盘」分组标题，保留原有设置项，其中自启选项显示为「开机自动启动」；语言及翻译服务由工作台控制，接口页的获取密钥链接显示为「获取密钥」。设置页局部滚动条常态为 6 逻辑像素圆角滑块，悬停区域与展开宽度为 12，最小滑块长度为 36，浅深主题增强对比；固定 18 像素留白避免卡片宽度随滚动条展开而变化。保存按钮始终固定在页底。

## 静默识别与三项快捷键

默认 F4 为静默识别，F5 为普通识别，F2 为截图并翻译。「设置 → 快捷键」提供三个独立的按键录入控件。托盘增加「静默识别」，工具栏「新建」仍遵循普通识别或截图并翻译模式；关于页移除退出按钮。

静默识别从可见窗口发起时，先最小化并隐藏主窗口；从托盘隐藏状态发起时直接保持隐藏，框选覆盖层正常显示。框选结束后在后台识别，成功时自动复制本次识别的原文，不请求翻译，不自动恢复主窗口。进度、取消及失败也不触发结果窗口；用户主动选择托盘「主界面」或「设置」仍可打开界面。普通识别和翻译保持原来的等待页与结果展示行为。

静默属性属于已接受的单次任务；忙碌时拒绝的新操作不能改变当前任务属性，下一次普通任务重新使用正常展示行为。异步通知按任务编号、忙碌/框选状态与取消状态过滤，防止迟到事件复制旧文本或恢复窗口。截图线程只提交结果和重绘通知，窗口是否恢复由界面线程根据本次任务决定。后台重绘与复制不依赖先显示窗口。

升级旧配置时，若缺少静默快捷键字段，原默认普通识别 F4 会在 F5 未被翻译使用时调整为 F5，静默识别使用 F4。其他现有识别/翻译快捷键优先保留；如 F4 已被占用，新增静默键从 F6 至 F24 依次选取不与它们重复的按键。此回退解决配置内的重复，不探测其他应用的占用；实际注册失败仍报告冲突。配置中已有静默字段时不再次迁移或重置三项快捷键。

2.0.0 历史轮次默认自动测试 83 项通过（库 69 项、界面程序 14 项），三组原生热键的冲突、回滚和注销测试已显式通过。当时 `target/ui-silent-final/report.json` 为 `complete=true`、`errors=[]`，21 个界面场景完成，快捷键录入检查未因焦点而延后。托盘隐藏状态下的静默成功、取消、错误及旧消息过滤通过，后续普通识别正常恢复窗口；当时的宽窄设置页和关于页已视觉复核。该历史结果不覆盖 2.0.1 固定窗口与关闭行为修复，当前结果见 [验证记录](VALIDATION.md)。

## 快捷键录入与截图窗口行为（2026-09-06 追加）

快捷键页采用按键录入：点击对应控件后，直接按下单键或组合键，不要求用户手动输入快捷键名称。新的按键组合保留在设置草稿中，保存成功后才注册并同步更新主界面提示和托盘菜单标签；取消设置、热键冲突或保存失败时保留原来生效的快捷键。三项按键组合不能重复；当前默认值为静默识别 F4、普通识别 F5、截图并翻译 F2。

工具栏「新建」、全局快捷键和托盘三项截图入口使用相同的截图流程：可见窗口先最小化并隐藏；已经隐藏的窗口跳过最小化，只确认隐藏状态，再捕获屏幕、进入框选。这样可避免从托盘发起截图时因隐藏窗口没有最小化状态而被错误拦截。普通识别与翻译在框选完成提交任务后恢复主窗口，显示等待页及任务进度；静默识别保持后台处理。

初始窗口在当前显示器的工作区居中，位置计算排除任务栏占用区域。设置页返回按钮缩短为「返回」；托盘悬停提示仅为「SightOCR」，快捷键仍显示在对应菜单项旁。

静默扩展之前的这一轮交互已通过自动测试及原生窗口冒烟验证：默认测试 77 项通过，21 个界面场景完成。录入已注册快捷键时可捕获按键并抑制重复截图；截图窗口门控验证最小化、隐藏及恢复，初始居中验证通过。该历史结果不覆盖新增静默流程。工具栏、托盘与全局热键共用截图路径已经代码复核，未逐项执行人工点击或保存真实桌面截图；多显示器混合 DPI 仍需目标环境验证。

## 代理与等待页（2026-09-06）

代理页提供「跟随系统（默认）」「不使用代理」「手动代理」三种模式。模式选择位于上方卡片，手动地址及可选认证位于下方卡片；非手动模式将这些字段置灰，同时保留草稿内容。地址支持 HTTP、HTTPS、SOCKS5、SOCKS5H，用户名和密码分开输入，密码默认遮罩。字段随窗口可用宽度排布，保存/取消仍固定在底部。页面不提供未经真实请求验证的连接成功状态。

「跟随系统」优先读取代理环境变量，再读取 Windows 手动代理设置，不执行 PAC/WPAD。代理仅作用于 SightOCR 的云端识别和翻译，不修改系统或其他应用；保存后对新任务生效，本地 OCR 不需要网络。

等待页面根据实际阶段显示「正在识别截图」或「正在翻译文字」。阶段随后台进度更新，服务名和目标语言取自提交时的任务快照；计时与取消入口始终可见。截图并翻译流程在收到 OCR 原文后先展示原文，再等待译文。点击取消立即恢复操作，显示「已取消 · 可以开始新任务」；独立识别进程被终止，不再等待 HTTP 超时或 DLL 返回。迟到通知按任务编号和忙碌状态过滤。

## 接口与托盘入口

接口页使用一个选择器和一张详情表单，七项依次为百度 OCR、腾讯 OCR、百度翻译、腾讯翻译、Mistral OCR、OpenAI、NVIDIA。切换表单不会丢弃本次未保存的其他服务配置，避免连续展示七张大卡片。密钥默认遮罩，可临时显示；填写状态仅表示字段是否完整，不表示在线连接已经验证。

Mistral 提供 OCR 配置；OpenAI、NVIDIA 提供 OCR 与翻译配置。三家各自维护独立 API Key 和 Base URL，后两家分别编辑识别模型与翻译模型；地址、模型采用普通输入框。提示值与 `Config::default()` 保持一致：Mistral 为 `mistral-ocr-latest`，OpenAI 为 `gpt-4.1-mini`，NVIDIA 为 `qwen/qwen3.5-122b-a10b`。原有百度/腾讯的识别和翻译凭据仍分别配置。

托盘悬停提示仅显示「SightOCR」，菜单按顺序提供「主界面、静默识别、截图识别、截图翻译、设置、重启、退出」七项。三项截图操作右侧显示已生效的快捷键，只有成功提交热键配置后才更新；冲突或保存失败时保留原显示。重启在关闭当前界面、释放工作线程、热键及单实例锁后启动新进程。常用动作无需先恢复主窗口。

## 视觉与 Windows 行为

工具栏采用浅蓝灰 #F1F3F9，画布 #F8F9FC，白色结果区域与蓝色强调，配套中性深色方案。按钮高32、控件圆角4、卡片圆角8，正文14（均为逻辑像素）。无左侧导航和工作台大标题。默认系统鼠标指针，控件提供悬停、按下、禁用与键盘焦点反馈。

主窗口客户区默认 740×680、最小 740×580 逻辑像素，允许调整大小及最大化，不设置应用级最大尺寸限制。默认尺寸在 150% 缩放下对应 1110×1020 物理像素。原文和译文在默认宽度下使用紧凑分页，宽窗口切换为左右对照。

多语言正文仅在内容、样式、布局或可见性实际变化后，于主界面交换 OpenGL 缓冲后刷新；稳定内容不随每个主界面帧重复擦除和重绘，避免日期、时间、数字及复杂文字闪烁。下拉菜单遮挡正文时，仅裁除菜单和阴影覆盖的原生区域，保留其余文字，并把键盘焦点交还菜单所在的主界面；菜单关闭后恢复完整正文。焦点切换保留原文和选区。设置、等待和模态界面仍按页面状态隐藏正文。

滚轮按鼠标所在的可见正文滚动，无需先点击获得焦点；原文和译文各自保留滚动位置。原生控件与主窗口共同转发一次原始滚轮消息，不因另一栏的键盘焦点而滚错正文。语言菜单覆盖处由主界面处理，菜单关闭后正文立即恢复滚轮响应。

Segoe UI Variable / Segoe UI 从系统字体目录加载，中文使用微软雅黑等系统字体回退，韩文使用 Malgun Gothic 等系统字体回退，日文使用 Yu Gothic 等系统字体回退；比例与等宽文本均注册回退，不打包系统字体。原生 DWM 标题栏同步深浅色与圆角，保留系统标题栏、拖动、调整大小、最小化及最大化。较旧 Windows 不支持的 DWM 属性自动忽略。内容背景为不透明表面，未启用 Mica 材质。

品牌和光标使用用户指定资源：`assets/icon.ico` 用于 EXE、托盘及安装器，`assets/icon.png` 用于窗口与关于页，`assets/cursor/cross.png` 用于截图选择光标。原图保持不变，编译时嵌入程序；一般界面控件保留 Windows 标准指针。

截图框选恢复旧 `src/screenshot.py` 的样式：`#FFFFFF`、1px 白色边框；选区外为原图一半亮度，选区内保留清晰原图。窗口绘制只呈现已经合成完成的帧，避免暗层、清晰选区和边框分次画到屏幕产生中间帧闪烁。

合成复用既有两张 DIB：一张保存只读原始截图，另一张作为离屏预览缓冲。鼠标移动时更新前后选区覆盖的区域，在离屏缓冲中组合背景、选区与白边，`WM_PAINT` 再以一次 `BitBlt` 提交完整区域。最终 OCR 像素始终来自原图，不包含预览暗化或边框；不为每次鼠标移动额外创建全屏图像。

设计参考：[微软几何规范](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry)、[字体规范](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography)、[DWM 窗口属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)。

## 界面验证

运行 `cargo run --locked --bin SightOCR -- --smoke-ui target/ui-current`。测试使用临时配置与合成文本，仅保存程序自身 framebuffer，不截取其他程序，不调用在线服务，不修改用户密钥、启动项或剪贴板。截图使用测试专用低冲突热键，产品默认值为 F4 静默识别、F5 普通识别和 F2 截图并翻译。

历史检查范围包括主界面、识别/翻译空白状态、常规设置、服务表单、网络代理页、关于/Logo、深色模式、760×640 窄窗口，以及 740×580 的译文错误提示、设置与处理中状态。旧报告保留作历史记录，不能替代当前改动的验证。当前仍以 2.0.0 重新打包，应检查默认 740×680、最小 740×580、拖动调整大小、最大化与还原，以及快捷键页重复标题移除。首次关闭、系统集成不可用时关闭、原文/译文分页与左右对照、先展示原文再等待翻译、计时与取消、迟到事件过滤，以及合成图中的框选亮度、白边和原图不变性继续属于回归范围。此次结果由验证记录补充；截图生成成功本身不代表没有布局问题。

静默流程的新增检查应覆盖平台动作、合成框选结果、识别进度和完成事件的完整传递；成功、取消、框选失败及识别失败均需确认没有自动显示窗口。复制通过独立测试接收端检查本次文本和次数，失败、取消与旧任务事件不得复制；此检查不写入真实剪贴板，也不代表验证了操作系统剪贴板写入成功。随后应检查普通识别恢复窗口、三项按键录入，以及静默期间主动打开主界面/设置，防止模式或窗口状态遗留。
