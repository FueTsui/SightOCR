# Rust 重构记录

运行入口为 `rust/main.rs`，没有 Python 子进程或 PyO3 桥接。UI 线程拥有配置、egui 界面和原生 RichEdit 正文控件；持久的私有识别子进程独占 OneOCR、COM apartment 和 HTTP 缓存，单一监督线程通过匿名管道传递任务和结果；截图和托盘分别使用原生消息循环。请求使用配置快照、编号与最多一个待处理任务。取消时终止自建识别子进程，界面立即空闲，后续任务重新创建引擎进程。Windows Job 在主程序异常退出时回收子进程；配置凭据和图片不写入命令行或临时文件。

| 原实现问题 | Rust 实现 |
| --- | --- |
| 多语言缺字与复杂排版 | 系统字体回退与原生 Unicode RichEdit 文本编辑区 |
| 网络/DLL 阻塞导致取消仍等待 | 持久可终止识别子进程、任务编号隔离、单任务监督 |
| 界面与工作线程耦合 | 平台、配置、引擎、服务、GUI 分离 |
| COM 初始化/调用/清理可能跨线程 | 在一个线程创建、使用、销毁，不实现 Send |
| 部分初始化泄漏，错误字符串混入识别结果 | 句柄 RAII、Result 传播错误 |
| 百度令牌缓存不区分凭据 | 缓存绑定凭据指纹 |
| 云端失败永久切换接口设置 | 本地回退显示原因，保留原选择 |
| 相同语言擅自改变目标 | 返回原文 |
| 翻译可能只取首段 | 保留完整返回段落 |
| 表格结束索引导致多余行列 | 排他结束索引与矩阵尺寸限制 |
| 科学计算依赖较大 | Rust 自适应局部对比、多尺度线段与文字坐标融合，TSV 输出 |
| 安装目录配置写权限问题 | APPDATA、旧配置迁移、原子保存 |
| 热键更新失败丢失原组合 | 新组合注册成功才释放旧组合 |
| 强制管理员启动、安装脚本按名称杀进程 | 普通用户运行，安装器按完整路径识别进程，确认后先正常退出；自动更新等待退出后覆盖 |
| 关于页仅链接发布网站 | 后台检查、下载并校验官方安装包，完成后自动安装和重启 |
| 截图磁盘 IO 及清理线程 | 内存截图 |
| 旧 Edge 翻译授权返回 404 | 改用同属微软的 Bing 网页会话接口 |
| 隐藏窗口忽略常规重绘请求 | 向本进程 HWND 投递原生消息，取消结果仍保持隐藏 |

截图先提交主窗口最小化/隐藏意图，等待新的渲染帧提交后再启动屏幕捕获；已隐藏的窗口保持隐藏。普通结果恢复也按渲染帧安排，界面状态与原生窗口操作在主窗口线程同步。egui 同一帧内的多次布局 pass 不代表已经提交新帧，不能据此提前捕获或恢复窗口。

## 验证命令

```powershell
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo test --locked --lib -- --ignored --test-threads=1
cargo run --locked --bin SightOCR -- --smoke-ui target/ui-smoke
cargo build --release --locked
```

真实 DLL 测试使用仓库 OneOCR 资源和无敏感内容测试图。默认测试不需要桌面交互或真实云端密钥。

`--smoke-ui` 仅在 Debug 构建提供：隔离配置、不修改剪贴板、不访问网络，输出主窗口/设置页截图和 JSON 报告，验证启动隐藏、后台结果唤醒、取消结果保持隐藏和显示事件恢复后自动退出。

## 人工回归

1. 默认 F4 静默识别中英文截图，成功后复制原文，不弹出等待页或结果窗口；取消和失败不复制旧结果，也不自动恢复主窗口。
2. 默认 F5 普通截图识别，确认新帧隐藏主窗口后才开始捕获，截图不含主窗口；完成后结果窗口恢复并置前，原文与剪贴板一致。
3. 默认 F2 截图识别并翻译，先展示原文再等待译文；翻译失败的错误信息不能当作译文复制。
4. 反向拖选、空区域、右键/Esc、负坐标与混合 DPI。
5. 关闭窗口后保持后台运行，隐藏托盘图标或系统集成服务不可用时也不退出；检查主动恢复、再次启动唤醒，以及托盘明确退出/重启。
6. 静默识别、普通识别、截图并翻译三种动作的快捷键录入、重复校验、冲突回滚与相互交换，确认仅保存成功后更新注册和托盘标签。
7. 连续按热键、取消后重试，旧结果不覆盖新结果；同帧多次布局不能提前启动截图或重复恢复窗口。
8. 配置迁移、Unicode 路径、损坏或不可写文件。
9. 锁屏/解锁、睡眠恢复、Explorer 重启。
10. 自有云端测试账号验证文字/表格/公式/翻译、过期凭据及配额错误。
11. 默认客户区 740×680、最小 740×580 逻辑像素；拖动调整大小、最大化与还原均可用，不设置应用级最大尺寸限制。确认窄窗口分页与宽窗口左右对照切换，截图恢复后保留尺寸和最大化状态。
12. 快捷键页直接显示三种动作的录入控件，无重复分节标题；缩至最小尺寸后保存和取消仍可见。

DLL 与网络请求不能强制中断，退出需等待当前调用释放资源。复杂合并单元格、倾斜表格不承诺与旧算法完全相同。没有跨机器性能基准，不将依赖减少表述为已实测的内存或速度提升。

协议依据：[百度表格](https://ai.baidu.com/ai-doc/OCR/Al1zvpylt)、[腾讯表格](https://cloud.tencent.com/document/api/866/86721)、[腾讯 TC3 签名](https://cloud.tencent.com/document/api/213/30654)。Bing 使用微软网页兼容端点，不是承诺稳定的公开 API；翻译失败不会自动转发其他供应商。
